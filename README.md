## 🚦 V2X Smart Traffic Simulation

**Overview:**  
This project simulates a real-time smart traffic management system using Vehicle-to-Everything (V2X) communication at a busy 4-way intersection. I developed the system using SUMO and Python to model adaptive traffic control, emergency vehicle priority, and weather-based behavior. It includes a live dashboard built in Tkinter for monitoring and interaction.

**What I did:**
- Designed the SUMO road network and traffic flow
- Programmed emergency vehicle priority and rain-response behavior
- Developed the GUI dashboard to control and visualize the simulation
- Integrated real-time traffic logic using TraCI and visual alerts
